## 업그레이드 구조

### 주 모듈 + 서브 모듈

```
주 모듈:  [Lv1] → [Lv2] → [Lv3] → [Lv4]   (선형 성능 강화)

서브 모듈: [A] 또는 [B] 중 택1              (1회성 특성 부여)

→ 두 모듈은 독립적으로 업그레이드 가능
```

- **주 모듈 (Main)**: 4단계 선형 업그레이드. 공격력·사속·사거리 등 전반적 성능 강화
- **서브 모듈 (Sub)**: 2개 중 택1. 상태이상 부여, 스플래시 추가 등 특성 부여
- 주 모듈과 서브 모듈은 **독립적**. 어느 순서로든 업그레이드 가능
- 서브 모듈 선택은 **되돌릴 수 없음**

### 업그레이드 조건

| 구분 | 조건 | 비용 자원 |
|------|------|-----------|
| 주 모듈 Lv2 | Lv1 보유 | 골드 |
| 주 모듈 Lv3 | Lv2 보유 | 골드 |
| 주 모듈 Lv4 | Lv3 보유 | 골드 |
| 서브 모듈 | 미선택 상태 | 골드 |

- 업그레이드는 **배치된 타워**에 현장에서 적용 (배치 후 업그레이드)
- 웨이브 중에도 업그레이드 가능

### 판매 환불

- 판매 시 **배치 비용 + 주 모듈 비용 + 서브 모듈 비용의 일정 비율** 환불
- 기본 환불율: 50%

## 타워별 서브 모듈 요약

| 타워 | Sub A | Sub B |
|------|-------|-------|
| **Basic Shooter** | Elite (스탯 보너스) | Frost (감속 부여) |
| **Bomb Shooter** | Wide Area (스플래시 확대) | Incendiary (화상 부여) |
| **Pierce Shooter** | Rapid Fire (공격속도 강화) | Impact (기절 부여) |
| **Slow Shooter** | Frostbite (화상 추가) | Freeze (감속 강화) |
| **Rapid Shooter** | Enhance (공격력 강화) | Spread (스플래시 부여) |

> 각 타워의 외관은 프리팹 내 부속물 오브젝트로 정의됨

## 프리팹 구조

### 부속물 계층

타워 프리팹 내에 각 단계별 부속물을 비활성 자식 오브젝트로 배치.

```
Tower_BasicShooter
├── Body (기본 본체)
├── FirePoint (발사 지점)
├── RangeIndicator (사거리 표시)
├── Main_2 (비활성) ← 주 모듈 Lv2 부속물
├── Main_3 (비활성) ← 주 모듈 Lv3 부속물
├── Main_4 (비활성) ← 주 모듈 Lv4 부속물
├── Sub_a (비활성)  ← 서브 모듈 A 부속물
└── Sub_b (비활성)  ← 서브 모듈 B 부속물
```

### 부속물 활성화 규칙

업그레이드에 따라 고정된 이름 규칙으로 자식 오브젝트를 활성화.

| 구분 | 오브젝트 이름 |
|------|--------------|
| 주 모듈 Lv2 | Main_2 |
| 주 모듈 Lv3 | Main_3 |
| 주 모듈 Lv4 | Main_4 |
| 서브 모듈 A | Sub_a |
| 서브 모듈 B | Sub_b |

## 외관 변화 원칙

업그레이드마다 기존 외관 위에 **부속물이 추가**되는 방식으로 변화를 표현한다.
모델 전체를 교체하지 않고, 레이어를 쌓아올려 업그레이드 단계를 직관적으로 인지할 수 있게 한다.

| 변화 요소 | 설명 |
|-----------|------|
| 부속물 추가 | 유니티 기본 도형(원, 사각형, 삼각형, 캡슐)으로 구성된 부속물이 단계별로 부착됨 |
| 이펙트 추가 | [TODO] 4단계에서 상시 파티클/발광 이펙트 |

## 밸런스 참고 사항

- 각 타워는 BTD(Bloons Tower Defense) 시리즈의 영향을 강하게 받음
  - Basic Shooter ← Dart Monkey, Bomb Shooter ← Bomb Tower, Pierce Shooter ← Super Monkey, Slow Shooter ← Glue Gunner, Rapid Shooter ← Sniper Monkey
- BTD5 기준 각 업그레이드의 수치와 비용을 일부 차용
- 단, 현재 시스템 내에서 적용 가능한 부분 위주로 차용하였으며, 일부는 다른 수치나 효과를 가지도록 조정함
- 구체적 수치는 플레이테스트를 통해 추가 조정 예정
