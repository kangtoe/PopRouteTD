# 적 스폰 시스템

적이 생성되는 방식과 웨이브 진행을 정의하는 문서

> 관련 문서: [적 유닛](Enemies.md) | [게임플레이](Gameplay.md)

---

## 개요

- 무한 모드 기반, 웨이브가 끝없이 진행
- 웨이브 구성은 WaveTable(ScriptableObject)에 수동 정의
- 5웨이브 간격으로 마일스톤 웨이브(물량 러시 / 엘리트) 등장

---

## 요소

- **웨이브 번호**: 현재 진행 중인 웨이브 (1부터 시작, 무한 증가)
- **스폰 그룹**: 한 웨이브 내에서 순차적으로 생성되는 적 묶음 (레이어 + 변형 + 수량 + 간격)
- **웨이브 간 대기**: 현재 웨이브의 마지막 적 스폰 후 다음 웨이브 시작까지의 대기 시간

---

## 데이터 구조

### WaveTable (ScriptableObject)
- 단일 에셋에 모든 웨이브 정의
- `List<WaveData>`: 인덱스 0 = 웨이브 1, 인덱스 1 = 웨이브 2, ...

### WaveData
- `List<SpawnGroupData>`: 해당 웨이브의 스폰 그룹 목록

### SpawnGroupData
| 필드 | 타입 | 설명 |
|------|------|------|
| layer | EnemyLayer | 적 레이어 (Red~Purple) |
| variant | EnemyVariant | 변형 (Normal/Shielded/Enhanced/EnhancedShielded) |
| count | int | 스폰 수량 |
| interval | float | 그룹 내 스폰 간격 (초) |

## 동작

### 웨이브 시작
- 준비 단계 종료 후 스폰 그룹 순서대로 적 생성 시작
- 그룹 내 적은 스폰 간격에 따라 순차 생성

### 다음 웨이브 전환
- 다음 중 먼저 충족되는 조건으로 다음 웨이브 시작:
  - **클리어**: 현재 웨이브의 모든 적(하위 레이어 포함) 제거 → 준비 단계 진입 후 다음 웨이브
  - **시간 경과**: 마지막 적 스폰 후 대기 시간 경과 → 잔여 적이 남은 채로 다음 웨이브 즉시 시작
- 시간 경과로 전환된 경우 잔여 적은 필드에 남아 계속 이동 (웨이브가 겹칠 수 있음)

---

## 웨이브 유형

웨이브 구성은 수동이지만, 설계 시 다음 유형을 기준으로 한다.

### 일반 웨이브
- 최고 레이어 일부 + 하위 레이어로 구성
- 표준 스폰 간격

### 물량 러시 (웨이브 5, 15, 25, ...)
- 하위 레이어 위주, 수량 증가, 짧은 스폰 간격
- AOE·커버리지 체크 목적

### 엘리트 (웨이브 10, 20, 30, ...)
- 최고 레이어 + 변형 적 소수 구성
- 단일 DPS 체크 목적
- 변형 에스컬레이션:
  - 1차 (웨이브 10): Shielded
  - 2차 (웨이브 20): Enhanced
  - 3차+ (웨이브 30~): EnhancedShielded

---

## 기타 특기 사항

- 스폰 그룹은 복수 가능 (예: 빨강 10마리 → 초록 3마리가 하나의 웨이브)
- 그룹 순서는 웨이브 설계에 따라 자유롭게 구성 (약한 적부터 고정하지 않음)
- 복수 경로 맵에서는 그룹별로 경로를 지정할 수 있음
- WaveTable에 정의되지 않은 웨이브 번호에 도달하면 스폰 없이 웨이브 완료 처리
