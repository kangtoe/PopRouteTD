# 아이템

필드에 생성되는 수집형 아이템의 종류, 획득 방식, 효과를 정의하는 문서

> **현재 상태**: 아이템 시스템은 미사용 상태. 코드 구조(ItemSpawner, ItemPool, GoldItem)만 유지됨

> 관련 문서: [게임플레이](Gameplay.md) | [적 유닛](Enemies.md) | [아군 유닛](Towers.md)

---

## 아이템 종류

### 골드 아이템
- **효과**: 획득 시 일정량의 골드 추가
- **골드 획득량**: 에디터에서 설정 가능

---

## 획득 방식

### 골드 생성기 생산
- 골드 생성기가 주기적으로 아이템을 필드에 생성
- 기존 골드 직접 추가 방식을 아이템 드롭 방식으로 대체

---

## 필드 드롭 동작

1. 아이템이 드롭 위치에 오브젝트로 생성
2. 플레이어가 아이템을 **탭하여 수집**
3. 수집 시 효과 즉시 적용 (골드 추가)

---

## 수치 (밸런싱)

| 항목 | 기본값 | 비고 |
|------|--------|------|
| 골드 획득량 | - | 에디터 설정 |
| 생성기 생산 주기 | - | 기존 골드 생성기 주기 활용 |
