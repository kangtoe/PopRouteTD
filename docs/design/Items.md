# 아이템

필드에 드롭되는 수집형 아이템의 종류, 획득 방식, 효과를 정의하는 문서

> 관련 문서: [게임플레이](Gameplay.md) | [적 유닛](Enemies.md) | [아군 유닛](Towers.md)

---

## 아이템 종류

### 에너지 아이템
- **효과**: 획득 시 일정량의 에너지 추가
- **에너지 획득량**: 에디터에서 설정 가능

---

## 획득 방식

### 적 처치 드롭
- 적의 최하위 레이어가 파괴(사망)되면 일정 확률로 아이템 드롭
- **드롭 확률**: 에디터에서 설정 가능

### 에너지 생성기 생산
- 에너지 생성기가 주기적으로 아이템을 필드에 생성
- 기존 에너지 직접 추가 방식을 아이템 드롭 방식으로 대체

---

## 필드 드롭 동작

1. 아이템이 드롭 위치에 오브젝트로 생성
2. 플레이어가 아이템을 **탭하여 수집**
3. 수집 시 효과 즉시 적용 (에너지 추가)
