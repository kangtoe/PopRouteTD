# 상태이상

적 유닛에게 적용되는 상태이상의 종류, 규칙, 저항을 정의하는 문서

---

## 상태이상 종류

모든 상태이상의 효과 수치는 고정이며, 타워는 종류와 지속시간만 결정한다.

### 화상 (Burn)
- 지속시간 동안 일정 주기로 데미지 적용 (DoT)
- 고정 수치: 0.5초마다 1 데미지

### 감속 (Slow)
- 지속시간 동안 이동속도 감소
- 고정 수치: 이동속도 50% 감소

### 정지 (Stun)
- 지속시간 동안 이동 완전 정지
- 정지 중에도 다른 상태이상(화상 등)은 정상 적용

---

## 적용 방식

- 타워가 보유한 상태이상 종류와 지속시간이 발사체를 통해 적에게 전달
- 발사체가 적에게 적중하면 데미지와 함께 상태이상 부여
- 스플래시 공격 시 범위 내 모든 적에게 상태이상 적용

---

## 중복 규칙

- 같은 종류의 상태이상이 재적용될 때 남은 시간보다 긴 경우에만 지속시간 갱신
- 서로 다른 종류의 상태이상은 동시에 공존 (정지 중 화상 DoT 등)

---

## 저항

- 적 유닛은 상태이상 저항값(0.0~1.0)을 보유
- 상태이상 적용 시 지속시간이 저항에 비례하여 단축
  - 실제 지속시간 = 원래 지속시간 x (1 - 저항)
- 저항이 1.0이면 상태이상 면역
