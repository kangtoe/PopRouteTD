# 적 유닛

기지를 향해 진격하는 적 유닛의 요소, 동작, 목록을 정의하는 문서

---

## 적 전용 요소

- **레이어**: 풍선의 껍질 단계. 피격 시 현재 레이어가 파괴되고 하위 레이어 풍선이 출현
- **체력**: 현재 레이어가 버틸 수 있는 피해량
- **이동 속도**: 경로 따라 이동하는 속도
- **골드 보상**: 처치 시 획득하는 골드

---

## 적 전용 동작

### 이동
- 스폰 후 경로 따라 이동
- 각 유닛별 고유 이동속도 적용

### 기지 도달
- 기지에 도달한 풍선은 현재 레이어 값만큼 생명 감소 (보라=7, 빨강=1)
- 생명 감소 후 해당 풍선 제거


### 피격
- 대상의 공격에 데미지를 받음
- 현재 레이어의 체력이 0 이하가 되면 레이어 파괴

### 레이어 파괴
- 현재 레이어가 파괴되면 하위 레이어 풍선이 같은 위치에 출현
- 하위 레이어가 없는 최하위 풍선이 파괴되면 완전 제거
- 레이어 파괴 시마다 에너지 획득

### 사망
- 최하위 레이어 파괴 시 완전 사망
- 사망 시 골드 드랍

---

## 유닛 목록

### 기본 풍선

레이어 기준 오름차순. 피격 시 현재 레이어가 파괴되고 바로 아래 레이어 풍선이 출현한다.
모든 풍선의 체력은 1이며, 이동속도는 빨강(1.0)부터 보라(4.0)까지 레이어에 비례하여 선형 증가한다.
- **1 빨강** → **2 주황** → **3 노랑** → **4 초록** → **5 파랑** → **6 남색** → **7 보라**

### 특수 풍선

- **철갑 풍선**: 일정 횟수의 피격을 무효화하는 장갑 보유. 장갑이 벗겨진 후 내부 기본 풍선이 출현
