# 적 유닛

기지를 향해 진격하는 적 유닛의 요소, 동작, 목록을 정의하는 문서

---

## 적 전용 요소

- **레이어**: 적의 껍질 단계. 피격 시 현재 레이어가 파괴되고 하위 레이어 적이 출현
- **체력**: 현재 레이어가 버틸 수 있는 피해량
- **이동 속도**: 경로 따라 이동하는 속도
- **골드 보상**: 처치 시 획득하는 골드
- **상태이상 저항**: 상태이상 지속시간 단축 비율 (0.0~1.0). 1.0이면 면역

---

## 적 전용 동작

### 이동
- 스폰 후 경로 따라 이동
- 각 유닛별 고유 이동속도 적용

### 기지 도달
- 기지에 도달한 적은 현재 레이어 값만큼 생명 감소 (보라=7, 빨강=1)
- 생명 감소 후 해당 적 제거


### 피격
- 대상의 공격에 데미지를 받음
- 현재 레이어의 체력이 0 이하가 되면 레이어 파괴

### 레이어 파괴
- 현재 레이어가 파괴되면 하위 레이어 적이 같은 위치에 출현
- 하위 레이어가 없는 최하위 적이 파괴되면 완전 제거
- 레이어 파괴 시마다 골드 획득

### 사망
- 최하위 레이어 파괴 시 완전 제거

---

## 유닛 목록

### 기본 적

레이어 기준 오름차순. 피격 시 현재 레이어가 파괴되고 바로 아래 레이어 적이 출현한다.
모든 적의 체력은 1이며, 이동속도는 빨강(1.0)부터 보라(4.0)까지 레이어에 비례하여 선형 증가한다.
- **1 빨강** → **2 주황** → **3 노랑** → **4 초록** → **5 파랑** → **6 남색** → **7 보라**

### 적 변형 (EnemyVariant)

기본 적에 변형을 적용하여 4종류 구성. 프리팹 자식 오브젝트 토글로 외관 구분.

| 변형 | 외관 | 효과 |
|------|------|------|
| **일반 (Normal)** | 기본 | 변화 없음 |
| **실드 (Shielded)** | 실드 부속물 ON | 별도 실드 HP 보유. 실드 파괴 시 일반으로 전환 |
| **강화 (Enhanced)** | 강화 부속물 ON | HP ×2, 속도 ×1.2, 보상 ×2 |
| **강화실드 (EnhancedShielded)** | 실드+강화+강화실드 부속물 ON | 강화 스탯 + 실드 HP. 실드 파괴 시 강화로 전환 |

#### 실드 동작
- 실드 HP는 본체와 별도 (기본 3)
- 데미지는 실드 HP를 먼저 소모, 초과분은 본체에 전달
- 관통 탄환은 실드를 1레이어로 취급하여 파괴
- 실드 파괴 시 variant 전환: Shielded→Normal, EnhancedShielded→Enhanced

#### 강화 동작
- HP, 속도, 골드 보상에 배율 적용
- 레이어 다운그레이드 시에도 강화 배율 유지
